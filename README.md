# Great Commerce

Vite + React + TypeScript storefront. Deployed to GitHub Pages.

- Live: https://daikomyo-media.github.io/ecommerce-site-challenge/
- Repo: https://github.com/daikomyo-media/ecommerce-site-challenge

## Local Dev

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes
- SPA routing supported on Pages via `404.html` fallback in workflow.
- Vite `base` is set to `/ecommerce-site-challenge/` in `vite.config.ts`.
